# DSH 0.2.0 桌面端：runtime 进 asar、旧 junction 悬空

**日期**：2026-09-28
**分类**：dsh-internals
**场景**：桌面端从 `0.1.7-rc.2` 升到 `0.2.0-rc.1` 后，排查插件问题时发现原先的取版本/取源码套路全部失效

## 背景 / 问题

0.1.7 时代可以在本机直接读 DSH 生态包源码：

```
C:\Users\xj\.dsh\profiles\node_modules\@deepseek-ai\dsh-app-boot\lib\index.js
```

升级后同样的路径 `readFileSync` 直接 **ENOENT**。`Get-ChildItem` 看得到条目名字，
但它是 **junction**（目录联接），而链接目标 `%APPDATA%\npm\node_modules\@deepseek-ai\dsh`
已经被删掉了 —— 桌面端不再用全局 npm 安装的 DSH。

## 结论

**0.2.0 桌面端把 runtime 内置进应用包**：

- 位置：`D:\DeepSeek Harness\resources\app.asar`
- asar 内 `dsh/package.json` 的 name/version：
  `@deepseek-ai/dsh-desktop-runtime` / **`0.2.0-rc.1`**
- 其中 `dependencies` 里的 `@deepseek-ai/*` **全部是 `0.2.0-rc.1`**，
  `@deepseek-ai/cordis` 是 `4.0.4`，共约 289 个 `@deepseek-ai` 包
- 判断当前桌面端版本的可靠来源：应用目录下 `resources/runtime.json` 的
  `"desktopVersion": "0.2.0-rc.1"`（app 目录里的 `version` 文件是应用版本 `44.0.0`，
  **不是** DSH 版本，别拿它当 runtime 版本）

配套的其它环境变化：

| 项 | 0.1.7 时代 | 0.2.0-rc.1 |
|---|---|---|
| runtime 位置 | 全局 npm `node_modules\@deepseek-ai\dsh` | `app.asar` 内 |
| `~/.dsh/profiles/node_modules/@deepseek-ai/*` | 指向全局安装的有效 junction | **悬空**（目标已删） |
| 启动日志 | `~/.dsh/logs/` | `%APPDATA%\@deepseek-ai\dsh-desktop\logs\`（`crash-*.log` / `main.log`） |
| 插件管理日志 | — | `profiles/<p>/.plugin-manager/logs/operation-*/pnpm.log` |
| profile 模板名 | `web` | `headless`（本机 `profiles/` 下为 `desktop` + `headless`） |

## 可复用要点

1. **`ENOENT` 不等于环境坏了**：先判断那个条目是不是 junction（`(Get-Item $p).LinkType`），
   再看 `LinkTarget` 是否还存在。
2. **asar 是可以直接读的**：asar 格式本身很简单（8 字节头 + JSON 目录表 + 拼接的文件内容），
   写个几十行的 reader（读 header → 解析 JSON 目录树 → 按 offset/size 切片）就能把
   `app.asar` 里的任意文件抽出来，不需要装 asar 工具。本次就是这样抽到
   `dsh-app-boot/lib/index.js` 并读到门禁实现 `evaluatePluginCompatibility` 的。
3. **要跑真机验证，别去修用户的 junction**：在临时目录 `npm install @deepseek-ai/dsh@<ver>`
   （官方包，带全部依赖，本次 542 个包约 9 分钟），用它的 `lib/bin.js` +
   独立 `DSH_HOME` 起沙箱 profile。真实环境保持原样。
4. **取 runtime 版本用 `getDshRuntimeVersion()`**（`dsh-app-boot` 的公开导出，
   读它自己 `package.json` 的 version）。这是门禁判定时用的同一个值，
   比自己拼路径更可靠。

## 相关路径

- `D:\DeepSeek Harness\resources\app.asar`（runtime 所在）
- `D:\DeepSeek Harness\resources\runtime.json`（`desktopVersion`）
- `C:\Users\xj\.dsh\profiles\node_modules\@deepseek-ai\`（悬空 junction，勿手动改）
- 抽取产物：`%TEMP%\asar_out\app-boot-020.js`
