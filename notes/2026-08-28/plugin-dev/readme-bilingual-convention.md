# README 双语约定：单文件切换，不拆分成两个文档

> 分类：`plugin-dev/` · 日期：2026-08-28

## 决定

仓库 README 采用**单文件双语**写法，禁止拆分成 `README.md` + `README.zh-CN.md` 两个文件：

- 文档顶部放语言切换行：`**🌐 语言 / Language：** [**中文**](#zh) · [English](#english)`
- 同一文件内：**英文在上**（`<a id="english"></a>` 锚点起的 English 区），**中文全量翻译在下**（`<a id="zh"></a>` 锚点起的 中文版 区）
- 中文优先——切换行里中文在最前，且中文版必须完整覆盖英文所有小节（含代码块、表格、链接），不是摘要

## 原因

- 用户偏好「优先中文」，但要保留英文版本供 GitHub 公开读者使用；
- 拆成两个文件会造成内容漂移（改英文忘中文、锚点/链接二处维护），单文件切换保证同步；
- GitHub 渲染的页内锚点（`#zh` / `#english`）即可完成切换，无需额外工具。

## 适用范围与例外

- 已应用：根 `README.md`（2026-08-28 重写）。
- 例外现状：`dsh-key-fallback/` 仍为拆分的 `README.md` + `README.zh-CN.md`（用户当时选择「仅根 README」范围，未并入本次改动）；后续若用户要求统一，按本约定合并回单文件。

## 可复用要点

1. 锚点写法：`<a id="zh"></a>` 放在 `## 中文版` 标题行之上，切换链接 `[中文](#zh)` 才能正确跳转。
2. 中文版每个小节都与英文版一一对应（目录结构、插件、安装、发布、约定、文档索引），代码块原样保留。
3. 涉及版本号/插件列表变更时，中英两区同步修改（遵守 AGENTS.md 规范 1）。
